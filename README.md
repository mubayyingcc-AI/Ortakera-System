# Ortakera Opportunity Network — multilingual website preview

A responsive, premium-positioned first-release website for Ortakera, with a Türkiye-first visual identity and an Istanbul/Bosphorus hero scene.

## Languages

The language selector switches the full interface between:
- English
- Türkçe
- العربية (right-to-left layout)
- Français
- Deutsch

The selected language is remembered in the browser. All major navigation, landing-page sections, service descriptions, opportunity lifecycle, contact form labels and notices are localized.

## Run locally

```bash
npm start
```

Open http://localhost:3000. The app uses Node's built-in HTTP server and has no production secrets or external runtime dependencies.

## Included
- Türkiye-inspired red, white and deep-navy visual system
- Istanbul/Bosphorus bridge hero scene and Turkish flag-inspired visual treatment
- Responsive navigation and five-language selector with RTL support for Arabic
- Business services, people/capability and WorkProof sections
- Opportunity-to-outcome lifecycle preview
- Contact/enquiry form with local-only preview behavior
- `/health` endpoint for deployment health checks

## Important preview boundary

The Istanbul hero artwork is a static generated visual, not a live camera feed. The enquiry form does not transmit or persist data on a server. No authentication, production CRM, payments, recruitment, legal eligibility decisions or regulated financial services are implemented. Those require the approved backend, database, privacy and compliance design before production use.
